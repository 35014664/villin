# Base de conocimiento de Villín

Cada archivo `.md` de esta carpeta es una respuesta de Villín.

## Añadir un tema

1. Crea un archivo `.md` con un nombre sin espacios, tildes ni eñes (por ejemplo, `wifi-del-centro.md`).
2. Copia esta estructura:

```
titulo: Nombre del tema
claves: palabra, frase con la que preguntaría el alumnado, otra frase
relacionados: contacto, horario
---
## Título de la respuesta

1. Primer paso.
2. Segundo paso.
```

3. Añade el nombre del archivo en una línea nueva de `indice.txt`.
4. Espera 1 o 2 minutos y pruébalo en https://35014664.github.io/villin/

La línea `---` es obligatoria. En el texto se pueden usar títulos (`##`), listas, `**negrita**` y `[enlaces](https://...)`.

**Aviso:** este repositorio es público. No incluyas contraseñas ni datos personales.
